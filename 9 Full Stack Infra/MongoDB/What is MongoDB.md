# What is MongoDB

> Document database. Stores JSON-like records ([[BSON and Documents|BSON]]) in [[Collections and Databases|collections]].

## Why it matters
- Flexible schema — fields can vary across documents
- JSON shape ≈ JS objects, easy mapping
- Strong horizontal scaling via [[Sharding]]

## When to choose
- Iterating fast on schema (early product)
- Hierarchical / nested data
- High write volume + horizontal scaling

## When not
- Multi-row joins are central → relational DB
- Complex transactions across many documents
