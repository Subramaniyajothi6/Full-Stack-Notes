# Common Coding Mistakes (interview)

- Off-by-one on array bounds
- Using `==` instead of `===` in JS
- Forgetting empty input edge cases
- Mutating input when problem forbids
- Using nested loops when hash map would help
- Recursion without memoization (TLE)
- Returning early before considering all branches
- Not handling negatives, zero, duplicates
- Building string with `+=` in a loop (use array push + join)
- Misreading time/space requirements

## Communication mistakes
- Silent thinking (talk through it)
- Coding before clarifying
- Not testing your own code
- Giving up at first bug instead of stepping through
