# Resume and Portfolio Tips

## Resume
- One page if <5 years experience
- **Bullets with impact** — "reduced p95 latency from 800ms to 220ms by adding compound index"
- Lead with verb, end with metric
- Skills section short — recruiters scan for keywords

## GitHub
- Pin top projects with READMEs
- Each README: problem, demo link, stack, key decisions, screenshots

## Portfolio
- One landing page linking projects
- Each project: 30-second demo video > screenshots > text

## Interview prep
- DSA daily warm-up (1–2 problems)
- One mock per week (Pramp / friend)
- Read company's blog/eng-blog before each interview
