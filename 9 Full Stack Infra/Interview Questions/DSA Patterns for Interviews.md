# DSA Patterns for Interviews

## Top patterns
- **Two pointers** — sorted arrays, palindromes
- **Sliding window** — substrings, k-elem sums
- **Hash map** — counts, lookups, anagrams
- **Stack** — parens, monotonic stack
- **Heap** — top-k, schedulers
- **BFS / DFS** — trees, graphs
- **Backtracking** — combinations, sudoku, n-queens
- **DP** — overlapping subproblems (knapsack, LIS, edit distance)
- **Binary search** — sorted arrays, search-on-answer
- **Union find** — connected components
- **Greedy** — interval scheduling, MST
- **Topological sort** — course schedule, build order
- **Trie** — prefix lookups

## Practice plan
1. Pick a pattern
2. 5 problems easy → medium
3. Solve from scratch, then read editorial
4. Re-solve a week later
