# Semantic Versioning

> Version is `MAJOR.MINOR.PATCH`.

## Rules
- **MAJOR** — breaking API changes
- **MINOR** — backward-compatible features
- **PATCH** — bug fixes only

## Range operators
- `^1.2.3` — `>=1.2.3 <2.0.0` (minor + patch)
- `~1.2.3` — `>=1.2.3 <1.3.0` (patch only)
- `1.2.3` — exact

## Pre-releases
`1.0.0-beta.1`, `2.0.0-rc.0`
