# What is NodeJS

> A runtime that executes JavaScript outside the browser, on top of [[V8 Engine]] + [[libuv]].

## Why it matters
- Same language frontend/backend
- Non-blocking, event-driven I/O — efficient for network/IO-bound apps
- Massive ecosystem via [[npm and package.json|npm]]

## Use cases
- REST/GraphQL APIs
- Realtime apps (WebSockets)
- CLIs and tooling (Vite, ESLint)
- Microservices

## Not great at
- CPU-bound work — blocks event loop. Use [[Cluster and Worker Threads]] or another runtime.
