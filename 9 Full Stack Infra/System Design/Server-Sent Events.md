# Server-Sent Events

> One-way push from server to browser over HTTP. Simpler than WebSockets.

## Use cases
- Live notifications, stock tickers, build logs

## Compared to WebSockets
- One-way (server → client)
- Auto-reconnect, last-event-id replay
- Plays well with HTTP/2
