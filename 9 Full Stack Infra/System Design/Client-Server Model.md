# Client-Server Model

> Client requests, server responds. The fundamental architecture of the web.

## Players
- **Client** — browser, mobile, CLI
- **Server** — handles requests, runs business logic, talks to DBs
- **Network** — TCP/IP, HTTP

## Stateless vs stateful
HTTP is stateless. State lives in DB, cache, sessions, or tokens.
