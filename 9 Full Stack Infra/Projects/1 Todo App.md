# 1. Todo App

> The "hello world" of MERN. Solidifies CRUD across all layers.

## Goal
Single-user todo list with create, edit, delete, mark-done.

## Stack
- React + Vite, fetch with `useEffect`
- Express + JSON body parser
- MongoDB + Mongoose

## Concepts practiced
- [[State in React|State]] · [[useEffect|useEffect]] · [[Forms in React|Forms]]
- [[Routing|Routing]] · [[REST API Design|REST]]
- [[CRUD Operations|CRUD]] · [[Mongoose Schema and Models|Mongoose]]

## Milestones
1. Backend `/todos` CRUD
2. Frontend list + add form
3. Edit inline + delete
4. Filter by status
5. Persist user from localStorage (no auth yet)

## Stretch
- Drag to reorder (`react-beautiful-dnd`)
- Optimistic UI

## Common mistakes
- Mutating state in React (`arr.push`)
- Missing CORS in dev
- No empty states
