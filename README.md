# Full-Stack Notes (MERN + Modern Infra)

A structured Obsidian vault covering the full MERN stack and modern engineering ecosystem — from JavaScript fundamentals to AI engineering, DevOps, and system design.

## Structure

```
.
├── MERN MOC.md                  # Master map of content — start here
└── 9 Full Stack Infra/
    ├── JavaScript/              # Language fundamentals → async → OOP → DOM
    ├── React/                   # Components, hooks, state, routing, performance
    ├── NodeJS/                  # Runtime, modules, streams, async patterns
    ├── Express/                 # Routing, middleware, auth, security
    ├── MongoDB/                 # Schemas, queries, aggregation, Mongoose
    ├── TypeScript/              # Types, generics, utility types
    ├── NextJS/                  # App router, server components, data fetching
    ├── PostgreSQL/              # SQL, indexes, Prisma, pgvector
    ├── Redis/                   # Caching, pub/sub, streams
    ├── System Design/           # HTTP, DNS, load balancing, CAP theorem
    ├── MERN Stack/              # Full-stack integration patterns
    ├── DSA/                     # Algorithms and data structures
    ├── DevOps/                  # Docker, Kubernetes, CI/CD, Terraform
    ├── Cloud/                   # AWS, GCP, Azure, serverless
    ├── AI Engineering/          # RAG, embeddings, agents, evals
    ├── Testing/                 # Unit, integration, E2E, Vitest, Playwright
    ├── Git and GitHub/          # Branching strategies, workflows
    ├── Interview Questions/     # Topic-wise Q&A banks
    └── Projects/                # Beginner → advanced project guides
```

## Note Format

Every atomic note follows a consistent template:

1. One-line definition
2. Why it matters
3. Core ideas (bullets / table)
4. Code example
5. Real-world usage
6. Common mistakes / pitfalls
7. Prerequisites + what to learn next
8. Best learning resources
9. Interview Q&A pairs

## Suggested Learning Path

| Weeks | Focus |
|-------|-------|
| 1–3   | JavaScript (closures, prototypes, event loop, promises) |
| 4–6   | React (hooks → state → router) |
| 7–8   | Node.js internals + Express basics |
| 9–10  | MongoDB + Mongoose, integrate with Express |
| 11–12 | Build a full-stack project |
| 13–16 | Full Stack Infra (Docker → CI/CD → AWS → AI) |
| Ongoing | System design + interview prep |

## Usage

Open the vault in [Obsidian](https://obsidian.md) for full wiki-link navigation, canvas roadmaps, and graph view. Each section has its own `*MOC.md` (Map of Content) as an entry point, and `.canvas` files for visual dependency flows.
